# SHAFTER V2

Application web mobile / PWA personnelle.

## Fichiers
- `index.html` : structure
- `style.css` : interface responsive
- `app.js` : navigation, objectifs, cours, quiz, sport et sauvegarde locale
- `manifest.json` : configuration PWA

Les données sont sauvegardées dans le stockage local du navigateur.
